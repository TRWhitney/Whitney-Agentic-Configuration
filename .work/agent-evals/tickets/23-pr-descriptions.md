# PR descriptions

**Status:** complete

## Accepted behavior

GitHub PR descriptions explain the problem, resulting behavior, example, practical need,
solution choice, setup and limits, and validation in seven ordered sections. A reader without
project or technical knowledge can understand the change and its consequences. Examples and
revision-specific links support the explanation. Small changes retain the structure without
inventing setup or tradeoffs.
