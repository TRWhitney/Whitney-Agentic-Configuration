# Add the comment reviewer to delivery review

Every complete review includes a distinct comment reviewer. Use the existing scope,
permission, fallback, and finding assessment rules for this reviewer. Examine comments in
the affected code even if the change did not edit the comments.

Adapt [pstack's Comment Sicko](https://github.com/backnotprop/pstack/blob/main/agents/comment-sicko.md)
using its removal default, exceptions, and treatment of uncertain external constraints.
Name the symbol behind an internal workaround or a suppression that hides a defect.
The reviewer reports findings, and the parent resolves confirmed findings.
