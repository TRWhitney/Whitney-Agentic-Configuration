# 02 Source record and transcript fidelity

**Status:** resolved
**Blocked by:** none
**Type:** discussion

## Question

What must the canonical source note preserve from a YouTube source, and which transcript cleanup
operations are allowed without compromising the source archive's evidentiary role?

## Answer

Treat the source note itself as the canonical faithful record. Preserve the transcript's wording,
order, qualifications, and useful timestamps. A container-to-Markdown conversion may remove format
control data only when it does not rewrite, summarize, deduplicate, restructure, annotate, or
silently correct the transcript. Add or normalize useful metadata separately from the source body.

Ignore sponsorships, filler, repetitions, padding, and non-transferable anecdotes only while
deciding what to integrate into knowledge notes; do not delete them from the archived source note.
Process every video independently, including videos in a shared series or course.

## Evidence

The original expanded draft required faithful source notes that are not summarized, restructured,
or annotated in place, while the requested YouTube path said the source document would be created
from a transcript. The draft was removed from the repository root after decomposition.

The draft explicitly permits metadata normalization, prohibits rewriting or restructuring the
transcript/source body, separates source preservation from knowledge integration, and permits
ignoring obvious non-knowledge content only during integration.
