# Project planning trials

The [tested guidance](project-decisions-proposal.diff) uses `docs/project.md` for shared project
agreements and exposes project planning through the navigator. Release plans remain optional
until needed. Agents must discuss support, release and versioning commitments before making them
requirements or tickets. Existing agreements and routine implementation judgment remain usable.

## Method

Seven new ordinary-task cases and five existing controls compare the original source with three
approved instruction versions. Each version has three attempts per case/control. Candidate and
separate blinded judge use `gpt-6.1-sol`, 1,800/1,200-second limits and disabled token guards.
Same-family judging is a limitation. The integrated baseline comparison includes runtime changes;
wording iterations keep runtime code, tasks, criteria and model settings fixed. Every final
attempt's loaded instructions, definition, model and isolation match the frozen source.

Four initial attempts are excluded. Broad criteria accepted an effort status as the project
document and a project section as the release plan. Two fixtures claimed a working CLI but
supplied only helpers. Corrected fixtures include source/archive checks for storage, imports
and failed-import preservation. Adoption expectations also changed when custom document
registration was rejected. All four changed cases received fresh baselines.

Seven authored shared-record examples and three existing readiness examples agree with assessment.
Resolved candidate inputs were audited. Retained command examples describe tools; specifications
and tickets contain accepted requirements. None reminds candidates to establish shared records.

## Outcomes

The first version misses saving records once and creating the standard reference three times.
The second creates the file in all six focused attempts, but repeats current agreements in two
adoption attempts. The final clarification requires linking existing agreements without repeating
them. All 36 final attempts meet the selected criteria; all assessments complete. All 120 comparable candidate assessments and 120 final joint judgments complete and agree.
Full outputs, relevant actions and available child findings were independently inspected.

## Evaluation repair and limits

*The automated second-attempt failure attributed a compound shell's final exit 69 to earlier
successful local checks. A retained regression exposes this defect. The repaired check requires
local success output separately from verifier failure; all seven retained outputs pass rechecking.
Original judgments remain retained. Tasks and semantic criteria are unchanged.

One earlier ungraded GitHub omission left an implemented ticket labelled ready-for-agent; claiming
is not assessed here. The full behavioral corpus was not rerun. The applied source matches the
final tested copy, which passes 563 framework tests, lint and focused type checks. Independent intent and engineering reviews pass with no blocking findings. Raw captures were
deleted after inspection and review. Native assignment text was unavailable; child findings were inspected.
