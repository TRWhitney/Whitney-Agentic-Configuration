# PR description trials

## Requirement and coverage

Accepted [PR 437](https://github.com/TRWhitney/Legend-of-the-Weir-King/pull/437) and
[PR 438](https://github.com/TRWhitney/Legend-of-the-Weir-King/pull/438) explain changes for
readers without project or technical knowledge. The [diff](pr-description-proposal.diff)
updates the existing shared GitHub guidance and links description-only edits to it.

One task files an inventory-export PR. The control rewrites a small help-page PR without
changing the repository or branch. Private checks inspect filed bodies, section order and
revision links. Semantic criteria cover comprehension, examples, separate reasons for need
and approach, setup, consequences and evidence. Requests supply no format reminders.

Baselines omit sections and separate rationale; small baselines also omit revision evidence.
First small attempts omit links; trigger attempt 2 omits the sections, rationale, revision links
and final reference. All-sections attempt 3 omits the final reference. These failures remain.

All 46 candidate assessments and 50 joint reassessments completed. Final joint judging agrees
with both baseline failures and all six final passes. Original judges missed link
omissions and inconsistently rejected understandable technical names. Independent comparison
with the accepted PRs rejects glossary demands; audience wording expansions did not establish
an improvement and are withdrawn. A stricter refusal-only judgment was disputed. Nonreplacement
combined with actionable retry instructions explains the practical restriction without a
prescribed refusal phrase or separate collision example.

## Assessment repairs and final comparison

Private checks initially miscounted the fixture's initial commit and rejected valid multi-issue
footers. Corrected checks accept the retained histories and footers. An unnecessary source
freeze was removed. Footer checks accept [GitHub closing syntax](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue). A link-presence check catches missing evidence links; semantic
assessment checks their relevance and revision.

Twelve independently authored examples cover valid concise explanations, meaningful context,
opaque internal descriptions, missing consequences, unsupported examples, stale validation,
missing sections and links replacing explanation. All 42 judgments across four calibration
rounds agree. The audience criterion now assesses necessary understanding across the whole
body. Fresh baselines precede the final repeats under fixed criteria. All six final attempts are
correct, three per case/control. The tested diff is applied unchanged and matches the instruction copy.

## Method and limits

Candidate and separate blinded judge use gpt-6.1-sol, 1800/1200-second allowances and disabled
token guards. Copies contain repository instructions and external unslop. Tasks, fixtures and
model settings remain fixed; grading repairs and older judgments are retained separately.
These reconstructed tasks use disposable GitHub/Git substitutes, not live publication.
Same-family judging and two domains limit generalization. The full corpus was not rerun.
All 494 framework tests, 153 definitions and quality checks pass. Independent intent and
engineering reviews pass with no findings. Raw evidence was inspected and reviewed outside the
checkout, then deleted. Fresh comparisons require fresh runs.
