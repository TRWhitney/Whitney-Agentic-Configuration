# Source Note Format

Use the vault's established source-note template and location. Follow these content rules within
that template.

- Record stable source identity, title, creator/publisher when known, original URL, publication
  date when known, transcript origin, language, and useful details about how the text was
  obtained or converted in established fields or a compact source header.
- For local ASR, record the engine version and model identity. State that the transcript is
  generated and may contain recognition or timing errors.
- Keep spoken wording, order, and line breaks unchanged, subject to the source-preservation
  rules for confirmed rolling-caption display repeats. Retain a useful timestamp for each
  remaining cue or complete caption block, preferably linked to the video.
- Keep observations made while preparing source evidence, verification, summaries, derived-note
  inventories, visual-assessment findings, and later corrections out of the source body.
- Keep the vault's expected source sections and names without inventing parallel section names.

The note should answer "what did this source say?" without pretending generated text is more
exact than its evidence.
