# Completion Report Format

Give one terse, scannable report after review. Omit empty categories.

```markdown
Changed
- Created: [[Note]]. Brief purpose
- Updated: [[Note]]. Meaningful change
- Visual: [[attachment]]. Source timestamp and use

Decisions
- [[Affected note]]. Exact approval needed and why

Notable findings
- Discrepancy, uncertain reversible placement, or other limitation that affects the result
```

Include only notes created, meaningful updates, retained visuals, structural or consolidation
suggestions, uncertain placements, factual discrepancies, proposed novel syntheses, substantive
material recommended for exclusion, commit results, and other approval decisions. Do not narrate
routine edits, commands, temporary files, or empty checks. Expand only when I ask.
