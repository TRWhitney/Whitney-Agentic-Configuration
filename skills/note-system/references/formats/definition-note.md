# Definition note

Use for a compact explanation intended to work in an Obsidian hover preview.

## Required structure

```markdown
# Canonical term

Define the term in one to three plain-language sentences. State the distinction most likely to
prevent misunderstanding.
```

Do not add frontmatter, properties, aliases, maintenance sections, source sections, related-note
lists, or an image gallery.

Choose one canonical filename. Express variants through wikilink display text rather than
properties:

```markdown
[[Definitions/Storytelling/Character foil|foils]]
```
