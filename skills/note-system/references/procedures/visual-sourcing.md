# Visual Sourcing Procedure

Obtain, create, or correct images for a stated purpose. Leave the decision to use them in the
vault to assessment.

## Find an image

Choose the method that fits the purpose:

- copy a screenshot, diagram, slide, comparison, example, or demonstration from a source;
- capture a clear frame from source media;
- obtain a reference photograph when appearance matters;
- create a diagram or infographic to explain the subject;
- correct a temporary copy using the assessment's findings.

## Prepare the image

Include enough context to avoid a misleading crop or frame. For video, inspect neighboring
moments if motion, an obstruction, or a transition makes the sample unclear. Extract from the
original video at suitable quality. If the prepared material lacks a needed image, report that
gap to the current state. A transcript alone cannot establish what was shown.

For reference images, record the source, creator, URL, and usage limits. For generated diagrams
or infographics, support every claim and relationship with sources, record how the image was
generated, and label it as generated. Do not use visibly watermarked content.

Keep images temporary and outside permanent attachment folders until assessment. Keep originals
and record corrections for comparison. Do not embed, permanently save, replace vault
attachments, or create permanent duplicates here.

## Result

Report each image's temporary path, purpose, how it was obtained or created, source and
timestamp where applicable, generation details, and usage or accuracy limits.
